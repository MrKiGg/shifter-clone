# Shifter Clone – Calendario de Turnos (Android)

Clon de **Calendario de Turnos (Shifter)** de LRHSoft.

## Funciones

- Vista mensual + modo **Pintar** y **Editar** (rangos y repetir patrón)
- Crear/editar turnos (color, horario, tarifa €/h)
- Notas y alarmas por día
- Estadísticas de horas e ingresos
- Widgets: mes, hoy, semana
- Exportar a Google Calendar / archivo .ics

## Build

Ver [BUILD.md](BUILD.md). Workflow de GitHub Actions genera el APK debug.

## Stack

Kotlin, Jetpack Compose, Material 3, DataStore, Glance widgets.
